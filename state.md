### 1. [x] «Одна стіна · Сім рішень» (index.html) — композиційний дисбаланс виправлено
Корінь проблеми: `.system-split` мав `align-items: stretch` на 900px+, а фото — `object-fit: contain`
(навмисно, щоб не кропати) → фото не розтягувалось на всю висоту вищого контейнера, лишаючи
порожній простір. Заодно виявлено реальний контент-баг: заголовок обіцяв «Сім рішень», а пунктів

  `materials-assembly.webp`, 1800×1350) замість `min-height: 280px` — фото показується без

- На 900px+: `align-items: stretch` → `align-items: start` + `.system-split__media { position:
  sticky; top: 7rem }` — фото «прилипає» під хедером, поки список (тепер 7 пунктів) скролиться

- **Побічна знахідка, яка блокувала sticky:** `body { overflow-x: hidden }` у Chromium/WebKit
  змушує `overflow-y` обчислюватись як `auto` (CSS 2.1 §11.1.1), через що `body` стає власним
  scroll-контейнером — і `position: sticky` усередині перестає працювати сайт-вайд (елемент
  «прилипає» відносно `body`, а не реального скролера документа). Виправлено перенесенням
  `overflow-x: hidden` з `body` на `html` — той самий захист від горизонтального скролу, без
  побічного ефекту. **Це site-wide фікс**, не лише для цієї секції.

- Кастомної play-іконки в CSS/HTML не знайдено (перевірено; лишається лише легітимний
